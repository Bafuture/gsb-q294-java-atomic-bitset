## 实现说明（分支 A）

### 组件

`com.example.gsb.bitset.AtomicBitSet`（`src/main/java/com/example/gsb/bitset/AtomicBitSet.java`）。

### 存储与无锁设计

- 位按 64 位字（`long`）存储，每 64 字组成一个固定大小的段（4096 位）。
- 段目录在构造时一次性分配（覆盖 int 下标全范围，约 2MB 引用数组），**永不扩容、永不拷贝**；段按需懒分配，经 CAS 发布后**永不替换**。因此任何线程持有的段引用永远有效，不存在"写到过期数组"的丢失窗口。
- 置位/清位均为字级 CAS 自旋，无全局锁。

### 并发扩容

扩容 = 向目录空槽位 CAS 发布新段。竞争失败的一方重试并复用胜者发布的段，已有位不受影响；读/清位遇到未分配区域直接按 0 处理，不触发扩容。

### 基数统计的一致性

`cardinality()` 与 `countRange(from, to)` 在并发修改下是**近似值**：逐字读取、不做全局同步，结果不是某一时刻的一致快照。无并发修改（静默）时返回精确值。

### 原子复合操作

- `testAndSet(index)` / `testAndClear(index)`：返回操作前的位值并更新。
- `testAndSetAll(indices...)`：批量置位，逐位原子生效（非整体事务），返回每位操作前的状态。

### 统计

`setCount()`（0→1 翻转次数）、`casRetryCount()`（CAS 失败重试次数，含段发布竞争）、`cardinality()`（当前置位数）、`wordCount()`（已分配字数）。

### 测试

- `AtomicBitSetTest`：基础位操作、复合操作、区间操作、自动扩容、统计。
- `AtomicBitSetConcurrencyTest`：8 线程压测——不相交区间混合操作与串行回放（`java.util.BitSet` oracle）逐位比对；同字 CAS 竞争收敛性；并发扩容不丢位；并发基数有界性；竞争下重试计数为正。
